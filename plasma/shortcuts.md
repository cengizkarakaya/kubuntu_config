# Arch to KWin shortcut contract
Meta+Enter: Alacritty
Meta+B: Brave
Meta+Space: KRunner
Meta+E: Dolphin
Meta+Q: close window
Meta+F: fullscreen
Meta+Shift+F: floating/tile switch (Polonium if supported)
Meta+H/J/K/L: focus left/down/up/right (Polonium action mapping required)
Meta+Shift+H/J/K/L: tile move (Polonium action mapping required)
Meta+R then H/J/K/L: Hyprland resize submap; not portable, use Polonium equivalent.
Print: Spectacle area to clipboard; Shift+Print: save screenshot.
Meta+Ctrl+L: lock via KScreenLocker.
Meta+1..0: virtual desktops 1..10.
Meta+N and Meta+Shift+N: KDE notification controls.
Meta+M: KDE power menu.
Meta+W: wallpaper UI.

NOTE: KDE Plasma 6 Wayland KGlobalAccel may not reload hand-written kglobalshortcutsrc reliably. GUI System Settings > Keyboard > Shortcuts is authoritative. Manual import/review is required before claiming exact mapping. Check existing conflicts, log out/in, test live.
