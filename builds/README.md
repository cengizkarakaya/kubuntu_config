# Build and vendor-install guidance

These pages describe general installation routes and acceptance checks.
They are not records of the software installed on a particular workstation.
Where a complete recipe is not available, that limitation is explicit.

Keep exact release/source digest, flags, dependency versions, prefix,
compiler/toolchain and dated smoke tests privately. Do not commit CMake
caches, package exports, shell histories or private source trees.

See the [scientific software guide](../docs/scientific-software.md) and
[Conda recovery](../conda/README.md).
