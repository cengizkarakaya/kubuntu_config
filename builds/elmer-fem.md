# Elmer FEM

No complete native build recipe is supplied. Select an official supported
release and follow its documented build or distribution instructions.
Do not infer compiler, CMake, MPI or dependency settings from an executable
directory. The optional scientific launcher detects installed software;
it does not install Elmer.

Verify both ElmerSolver and ElmerGUI, and validate a small solver example.
Keep the actual source revision, flags, dependencies and installation prefix
privately. GUI startup alone is not a numerical test.
